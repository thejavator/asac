# Code of Conduct

We are committed to a harassment-free, respectful and inclusive community.

**Expected:** kind and constructive communication, respect for differing viewpoints, accepting feedback gracefully, focusing on what is best for the project.

**Unacceptable:** harassment, discrimination, personal attacks, publishing others' private information, or other conduct inappropriate in a professional setting.

Maintainers may remove contributions and restrict participation that violate this code. Report concerns privately to the maintainers (contact to be set when the repository is published). This code is adapted from the principles of the Contributor Covenant.
