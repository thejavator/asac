# Feedback on ASAC 0.1

Thanks for trying it. Please answer these six questions, in the same order for everyone, in an
issue (template: "Feedback 0.1") or by mail. There is no telemetry: we only know what you tell us.

1. Did you reach the first gate without help? How long did it take?
2. What blocked or surprised you?
3. Did you look at `asac logs` or `asac audit`? Did it tell you something you would not have known?
4. If you used a `loop`: did it fix things you would have fixed yourself? How many turns, what cost?
5. Declared identity (`--by`, `--role` are not authenticated) is a known limit of 0.1. Is it
   acceptable for your use, or a blocker?
6. Would you use this on a real project? If not, what is missing? **One thing.**

Useful to attach, if you are willing: the output of `asac doctor` and `asac logs <run>` (check it
for anything you do not want to share first; it contains file paths and the agent's reasons).
