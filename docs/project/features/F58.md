# F58. Image de l'agent

**Statut : Vérifiée.** Spec : `asac-specs-v1.md`, § 6, lot C.

## Critères

| # | Critère | Preuve |
|---|---|---|
| 1 | Un Dockerfile construit une image avec `claude`, `git`, `python3`, étiquetée de la version d'ASAC | `src/asac/docker/agent/Dockerfile`. Construite pour de vrai : `docker inspect` rend `org.opencontainers.image.version=0.1.0` et `dev.asac.claude-code=2.1.331`. Dans le conteneur : `git 2.39.5`, `Python 3.11.2` |
| 2 | `docker run --rm <image> claude --version` affiche une version | Exécuté : `2.1.331 (Claude Code)`, y compris sous les options du runner (utilisateur 65534, racine en lecture seule, sans réseau, sans capacités) |
| 3 | `runner_image` par défaut désigne cette image | `test_the_default_runner_image_is_the_agent_image_of_this_version` (`tests/test_daemon.py`) : `DEFAULT_IMAGE == "asac-agent:" + __version__` |
| 4 | `asac doctor` signale l'image présente ou absente, avec la commande de construction | `test_a_missing_agent_image_comes_with_the_command_that_builds_it`, `test_a_present_agent_image_is_reported_by_name`, `test_the_image_checked_is_the_one_the_vars_file_names` (`tests/test_doctor.py`) ; vérifié contre le vrai Docker |

## Choix

- **Le Dockerfile vit dans le paquet** (`src/asac/docker/agent/`), pas à la racine : le wheel le
  porte, donc `asac doctor` peut donner la commande de construction depuis une installation par
  pip. `docker/agent` est un lien vers ce dossier, pour qui cherche à la racine.
- **Version de `claude` épinglée** (`CLAUDE_CODE_VERSION=2.1.331`, argument de construction) : une
  image reconstruite plus tard ne change pas d'outil sans que quelqu'un le décide.
- **Aucun secret dans l'image.** La clé du modèle est transmise au conteneur par son nom, au
  lancement (F61).
- `HOME=/tmp` : sous une racine en lecture seule, le tmpfs `/tmp` est le seul endroit où l'outil
  écrit ses fichiers. Ils n'entrent pas dans le worktree, donc pas dans le commit.

## Vérification

- `asac doctor` : l'image absente n'est pas bloquante (elle ne sert qu'aux étapes `delegate`).
  Mutation « image absente = erreur bloquante » : détectée.
- 6 mutations de `doctor.py` : message sans commande de construction, image par défaut ignorée,
  réseau toujours vérifié, réseau absent jugé présent, Docker muet jugé présent, image absente
  bloquante. Toutes détectées.

## Écart

L'image pèse 780 Mo (Node, git, Python et le binaire de `claude`). Elle n'est pas publiée dans un
registre : chaque poste la construit une fois (`asac doctor` donne la commande).
