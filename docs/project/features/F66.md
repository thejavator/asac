# F66. Gabarit `feature` exécutable

**Statut : Vérifiée.** Spec : `asac-specs-v1.md`, § 6, lot A.

`asac init --template feature` crée un projet qui valide, dont chaque fichier référencé existe, et
qui atteint sa première gate.

## Critères

| # | Critère | Preuve |
|---|---|---|
| 1 | Crée tous les fichiers du gabarit | `test_feature_template_writes_a_complete_project` |
| 2 | `asac validate` rend `0 error(s), 0 warning(s)` | `test_feature_template_validates_without_warning` |
| 3 | `.gitignore` créé ou complété, chaque ligne une fois, lignes existantes préservées | `test_gitignore_is_created_and_completed_not_overwritten` ; vérifié à la main sur deux passes `init` successives |
| 4 | Fichiers conservés sans `--force`, remplacés avec | `test_init_refuses_to_overwrite_without_force` |
| 5 | Le wheel contient `asac/templates/feature/` ; `init` marche depuis un environnement vierge | `tests/test_wheel_install.py` : construit le wheel, l'installe seul dans un venv neuf, lance `init` et `validate` |
| 6 | Pile autre que Python : `init` dit d'adapter `tests-green.sh` | `test_init_detects_stack_and_template` (`tests/test_golden.py`), pile Java |
| 7 | Parcours `init` → `vars check` (1) → copie → `vars check` (0) → commit → `apply` (2) → `SPEC.md` → `submit` ouvre `gate_<run>_requirements` | `test_vars_before_any_values_file`, `test_the_generated_project_runs_to_its_first_gate` |
| 8 | `--template minimal` crée un manifeste vide valide, seul fichier créé | `test_minimal_template_creates_the_manifest_and_no_other_file` |

## Changements

- `src/asac/templates/feature/` : le manifeste, deux skills, une instruction, trois hooks
  exécutables, `asac.vars.yaml.example`. Le nom du workspace remplace `__NAME__`.
- `src/asac/cli/__init__.py` : `init` lit le gabarit depuis le paquet, vérifie les conflits
  avant d'écrire, positionne le bit exécutable des `.sh`, complète `.gitignore`.
- Correction faite pendant la vérification : `minimal` créait aussi un `.gitignore`, ce que le
  critère 8 interdit. Il n'en crée plus.

## Vérification

- Critère 5, mutation : en excluant `src/asac/templates` du wheel, les 2 tests échouent.
- Critère 8, mutation : `minimal` qui recrée le `.gitignore` fait échouer le test.
- Le parcours du critère 7 tourne avec le harnais `claude-code` en conduite manuelle, sans appeler
  le vrai outil : le travail est écrit à la main dans le worktree, comme le ferait une personne.

## Écarts

- Le critère 6 est vérifié sur la pile Java ; les autres piles passent par la même branche.
