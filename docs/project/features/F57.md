## Ce que le moteur ne faisait pas avant

Avant ce travail, une étape `delegate` s'exécutait mais le moteur n'en tirait rien :

- le coût n'était **jamais enregistré** (`_exec_in_runner` ne lisait pas la sortie JSON) : un budget
  de coût ne voyait rien ;
- la **boucle ne tournait pas** : elle exige la trace « ASAC a lancé l'outil » (`tool.launched`),
  écrite seulement sous `autorun` ;
- un **rejet ne relançait pas** l'agent : la relance exigeait `autorun` ;
- le prompt envoyé à l'agent ne portait **pas** le message du contrôle ni la raison du rejet (il
  utilisait le texte du brief sans le retour que la boucle y ajoute).

Les quatre sont corrigés. `delegate` n'a pas besoin d'`autorun` : l'agent est lancé par le moteur
dans le runner, c'est le même acte.

## Vérification

7 mutations du moteur, toutes détectées : coût du rapport non lu, coût manquant compté zéro,
`tool.launched` non écrit, rejet qui exige `autorun`, prompt sans la raison, rapport en erreur
ignoré, sortie sans rapport non marquée « inconnue ». Les deux dernières n'étaient pas détectées
d'abord : j'ai ajouté les tests qui manquaient.

## Écart

Le réseau par défaut est `none`, qui coupe aussi la passerelle du modèle. Le test réel nomme un
réseau (`ASAC_REAL_CLAUDE_NETWORK`, défaut `bridge`). C'est le choix de l'opérateur (F60) ; ASAC ne
filtre pas ce réseau.
