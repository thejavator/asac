# F63. Validation du parcours délégué

**Statut : Vérifiée.** Spec : `asac-specs-v1.md`, § 6, lot A.

`asac validate` refuse une étape `mode: delegate` qui ne déclare pas de runner, à l'écriture du
manifeste, au lieu de laisser l'exécution échouer (« harness delegated the step but no runner is
placed »).

## Critères

| # | Critère | Preuve |
|---|---|---|
| 1 | `mode: delegate` sans `execution.runner` donne `ASAC028` (erreur), chemin `pipelines.<p>.steps.<s>.execution` | `test_a_delegate_step_without_a_runner_is_an_error_with_its_path`, `test_a_delegate_step_with_an_empty_execution_block_is_also_an_error`, `test_every_delegate_step_is_reported_not_only_the_first` |
| 2 | `mode: delegate` avec `execution.runner` est valide | `test_a_delegate_step_with_a_runner_is_valid` |
| 3 | `execution.fallback: assist` reste accepté | `test_the_fallback_stays_accepted_next_to_a_runner` |
| 4 | `ASAC028` ajouté à la plage de F1 | `docs/reference/resources.md` ; la spec cite encore `ASAC027` en F1 (voir « Écarts ») |

Une étape `assist` ne demande aucun runner : `test_an_assist_step_needs_no_runner`.

## Changements

- `src/asac/validate/checks.py` : contrôle `ASAC028` à côté de `ASAC013`.
- Les 12 manifestes qui avaient un pas `delegate` sans runner déclarent maintenant
  `execution: { runner: docker }` : `examples/payments-service/asac.yaml` et les scénarios de
  `tests/functional/`. Avant le contrôle, ils étaient valides et échouaient à l'exécution.
- `src/asac/adapters/runner_local.py` : `runner_kind: fake` (ou `ASAC_RUNNER=fake`) donne le
  `FakeRunner` en mémoire, comme `--harness fake` donne l'outil factice. La fixture
  `sandbox_project` le positionne : les tests hors ligne n'ont pas besoin de Docker.
- `tests/test_daemon.py` : l'aide `_delegate_project` ne réécrit plus le manifeste pour ajouter
  un runner ; il le trouve déjà.

## Vérification

- 6 tests ajoutés à `tests/test_validate.py`.
- 6 mutations de `checks.py`, toutes détectées : code changé, chemin sans `.execution`, contrôle
  étendu à toute étape, runner vide accepté, contrôle limité à l'absence du bloc, sévérité en
  avertissement.
- Suite complète : 709 réussis, 10 ignorés, 3 échecs attendus.

## Écarts

- La spec cite `ASAC001` à `ASAC027` en F1 ; le code émet maintenant `ASAC028`. La spec le prévoit
  (critère 4) : la plage de F1 est à lire « jusqu'à `ASAC028` ». Le fichier est gelé, l'entrée au
  § 17 est notée dans le tableau « Demandes de modification » du fichier `README.md` de ce dossier.
- Le scénario `tests/functional/02-feature/README.md` § 4e décrit l'ancien échec à l'exécution
  (« no runner is placed »). Il est mis à jour avec le nouveau message de `validate`.
