## Changements

- `docs/reference/cli.md` : réécrit. Il n'annonce plus de commande « cible » : il décrit celles qui
  existent. Les commandes non implémentées (`provider install`, `registry search`, `skill publish`)
  sont dites telles quelles.
- `docs/getting-started/quickstart.md` : réécrit pour le chemin que la version 0.1 supporte.
- `docs/getting-started/existing-projects.md`, `docs/visuals/readme-overview.html` : l'option
  `--mode observe` n'existe pas ; le texte et la sortie d'exemple inventée sont remplacés par la
  sortie réelle de `asac init`.
- `tests/functional/01-new-project/README.md` : étapes 1 à 3 réécrites. L'ancien texte annonçait
  un squelette à une étape et un avertissement `ASAC017` qui n'existent plus.
- `README.md` : ligne de statut. `init`, `run`, `plan`, `submit`, `vars` et `learn` rejoignent la
  liste ; le runner Docker n'est plus dit « non supporté » en bloc, seul Kubernetes l'est.
