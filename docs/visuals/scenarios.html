Feature

New feature — from Jira story to staging

A story is created in Jira. ASAC automatically orchestrates 5 agents and 4 gates and produces a complete evidence chain — without the team changing its existing Jira workflow.

Pipeline : feature
Maturity : L3
Estimated duration: 4-6h (excluding human gates)
Estimated tokens: ~42,000
Product Owner 09:00 Jira
Jira story creation
Alice creates story PAY-1234 "As a user, I want to receive an email notification when an international transfer is made" and adds the label asac-enabled.
The asac-enabled label is the opt-in. Without this label, ASAC does not intercept the story — teams keep control over what they hand to agents.
ASAC Daemon 09:00 webhook
Receiving the Jira trigger
The ASAC daemon receives the Jira webhook, detects the label asac-enabled, starts the feature pipeline for PAY-1234.

Bug fix

Urgent bug fix — accelerated hotfix pipeline

A bug in production: email notifications are not sent for USD transfers. The team triggers the hotfix pipeline — shorter, but SAST is still mandatory.

Pipeline : hotfix
Priority: P1
SLA : fix deployed < 2h
Reduced gates: SAST only (no coverage gate)
Developer 14:00 CLI
Manual trigger of the hotfix pipeline
Ben detects the bug via Datadog alerts. He creates a Jira ticket PAY-BUG-89 and triggers the hotfix pipeline manually — there is no automatic trigger for hotfixes.
$ asac apply --pipeline hotfix --trigger jira:PAY-BUG-89
Pipeline: hotfix (manual trigger)
Issue: PAY-BUG-89 — P1 · Notifications USD missing
Timeout: 4h (vs 72h for feature)

⚠ Hotfix mode: spec step skipped
⚠ Hotfix mode: coverage gate disabled
✓ SAST gate: active (non-negotiable)

▶ Step: development → agent: dev → mode: assist
Dev Agent 14:01–14:28 dev harness
Bug analysis + fix implementation
The dev agent analyses the logs, identifies the cause (missing currency code check in the event filter), and proposes the fix. In assist mode — Ben approves each change before it is applied.
agent dev — hotfix analysis
Analyzing PAY-BUG-89...
Reading logs: payments-service prod 2026-10-20

introduced in: commit a7f3c21 (PAY-1234)

- if (currency in [EUR, CHF, GBP])
+ if (currency in [EUR, CHF, GBP, USD])

Onboarding

New developer — productive in 30 minutes

Sara joins the payments team today. She has never used ASAC. She is autonomous on her first story before the end of the morning — without needing to know the team's SDLC.

Profile: Senior Java dev, first time with ASAC
Access: GitLab repo + Jira + ASAC portal
Sara (new dev) 09:00 CLI
Cloning the repo — the SDLC is already there
Sara clones the repo and sees asac.yaml. She does not need documentation about the process — the file describes exactly how the team delivers.
