# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Use the repository's private vulnerability reporting (GitHub Security Advisories) once enabled, or contact the maintainers privately. We aim to acknowledge reports within a few working days.

## Scope

ASAC currently ships a specification, documentation and examples; no executable runtime. Relevant reports include specification flaws that would lead implementations to be insecure (for example secret handling, gate bypass, privilege escalation between agents) and mistakes in the example policies.
