# Spécification

Écrivez `SPEC.md` à partir de `DESIGN.md` : le contexte, les **critères d'acceptation** (titre
« Acceptance criteria », chacun vérifiable), les routes de l'API appelées (méthode, chemin, réponse,
erreurs), les **permissions** système demandées avec leur justification, et ce qu'on ne fait pas.
